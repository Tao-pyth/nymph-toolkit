# ADR 0003 通信経路

## 状態

**最後の正式採用はCore経由のみ。直接接続を認める緩和案は未採用。Connections実装前に維持・緩和を判断する。** 記録日2026年11月19日。後続判断は未記入。

## 背景と履歴

| 順序 | 内容 | 採用状態 |
|---|---|---|
| 1 | 通信をCore経由のみとする | 最後の正式採用済み方針 |
| 2 | 直接接続を認める緩和案が出た | 未採用。許可条件と管理責任を含めて要決定 |
| 3 | 今回の引継ぎ依頼で、実装前決定事項として残すよう指定された | R2による記録方針 |

元会話内の各発言日時は未確認である。

## 決定

正式採用済みの方針を「Core経由のみ」として保持する。緩和案の存在だけでは採用状態を変更しない。Connectionsの経路と経路別受入テストを固定する前に、従来方針の維持または条件付き緩和を判断し、記録する。

## 影響

経路に依存しないRuntime・Registryなどの検討を進められる。経路を使う検証は採用済み方針を根拠にする。ダミーへの相互参照の受け渡しや軽量な呼び出し方式によって、未採用の直接接続を既定動作にしない。

R2に記載された正式採用と後発提案の関係。旧稿の「Adapterを中継した迂回通信は禁止」という個別断定は元発言を確認できていないため、上の確認事項へ移した。最後の正式方針であるCore経由のみという記録は保持する。[Docsの根拠表](../README.md)
