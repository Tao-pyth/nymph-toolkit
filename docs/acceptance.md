# 受入基準案と検証記録

以下は確定方針を確認するための**受入案**である。操作例や観察方法は提案として扱う。未決のAPI・失敗時動作を判断した後、期待結果を具体化する。現時点でCoreの実行検証は未実施である。

## バージョン別シナリオ

| ID・段階 | 根拠 | 入力・操作と検証手順 | 合格と判断できる結果 |
|---|---|---|---|
| P0 公開準備 | R3 | DocsとADRの状態表示・リンクを確認。Gitの対象ファイルと初回コミットを確認し、releaseの判断欄と照合する | 単一文書と個別Docsの内容が整合し、公開対象が説明できる。公開先・公開範囲・ライセンスが決定済み |
| A01 V0.1 | ADR 0001・0005 | 公開URLとタグを開き、READMEから各Docsへ進む。対象コミットを新しいフォルダへcloneする | 資料が取得でき、実装状況と未決事項が読める。`v0.1.0` とリリース記録が同じコミットを指す |
| A02 V0.2 | ADR 0002・0005 | development記載の環境構築後、Runtimeを起動し、ダミー処理を一度実行して停止する。採用した起動失敗も再現する | 開始・処理結果・停止完了を確認できる。失敗が契約どおり呼出側へ通知される |
| A03 V0.3 | ADR 0001・0005 | ダミーSubsystemとAdapterを登録、照会、解除する。重複・未登録解除は採用規則に合わせて試す | 登録状態が操作に追従する。稼働中着脱の採用範囲が分かり、範囲外入力への応答が契約に一致する |
| A04 V0.4 | ADR 0003 | 採用した経路で要求と結果を照合。拒否対象の接続を公開手段で試す。相手の解除・受信側失敗を再現する | 許可経路で受信を確認できる。拒否条件と失敗通知が採用ADRに一致する。緩和採用時は条件の内外を確認できる |
| A05 V0.5 | ADR 0004 | ダミーNymphが活動A、開始T、期間Dを指定。採用した時計で開始・終了を観察する | Nymphの入力と予定・実行結果を対応付けられる。期間終了の処理が採用した意味に一致する |
| A06 V0.6 | ADR 0004と変更の後続ADR | 開始前の期間DをD2に変更。実行中の変更・停止・取消は採用範囲で試し、競合と終了後の入力も確認する | 変更元の入力と変更結果を照合できる。競合・範囲外入力の応答が採用契約に一致し、活動状態の矛盾がない |
| A07 V0.7 | ADR 0002・0003 | 同一・別プロセスで通信・活動・変更を再現する。子プロセス終了や切断を起こす | 各配置が採用契約を満たす。共通部分と差異が記録され、失敗時の活動・接続状態を確認できる |
| A08 V0.8 | ADR 0001〜0005 | 起動→登録→接続→活動→変更→解除→停止のシナリオを両配置で行う。途中の失敗と、採用した再実行手順を試す | タスク・プロセス・接続の後処理が停止仕様に一致する。再実行時の状態が一貫し、採用した失敗時処理を再現できる |
| A09 V0.9 | 全採用ADR | 新しい環境で全採用シナリオを再現し、API資料・実装・結果を照合する | 合意したCore機能がダミーで検証できる。受入未達が解消され、既知の制約と残課題が明記されている |

A04の経路検証はCoreが提供する接続手段を対象とする。任意のPythonコードやOS通信を遮断する隔離機能の要件は未決である。

テスト用の時計や短い期間を利用する方法は提案である。時刻、待機の許容差、入力形式は時計の採用記録に合わせる。未検証の実行配置や項目は「未検証」と明記し、全体合格に含めない。

## 結果の記録方法

実装開始後、必要になった段階で `docs/validation/` を作り、`v0.x.md` に結果を残す案とする。

| 記録欄 | 内容 |
|---|---|
| 対象 | バージョン、コミットSHA、受入ID、根拠ADR |
| 環境 | OS、Python版、依存版、同一・別プロセスの区別 |
| 再現 | 実行コマンド、ダミー入力、時計条件、失敗の起こし方 |
| 結果 | 期待結果、観測結果、合格・不合格・未検証 |
| 残課題 | 原因、対応方針、次の検証対象 |

## 資料整備時の確認

- R2・R3の確定事項をすべて記載し、追加仕様には状態を付ける。
- ADR 0003で最後の正式方針と未採用提案を追える。
- V0.1の公開条件、V0.9の完成条件、各段階の成果物・判断・検証を記載する。
- Git未初期化から公開までの手順と公開前判断欄を掲載する。
- READMEからDocs・ADRへ到達でき、単一配布用引継ぎ書に各文書の本文を収録する。
